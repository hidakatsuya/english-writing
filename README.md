# English Writing

A simple editor for writing in English while keeping track of your word count.

## Features

- Real-time word count
- One-click copy
- Two-step clear to prevent accidental deletion
- Installable as a PWA with offline support
- Responsive layout
- Light and dark color schemes
- No external libraries or network requests
- Everything runs locally in your browser

## Browser support

The latest versions of Chrome, Firefox, and Safari are supported.
